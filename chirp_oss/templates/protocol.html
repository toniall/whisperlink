How {{ APP_NAME }} works

Physical layer

Each frame starts with a linear up-chirp preamble detected by FFT matched filtering, then 4 LFSR training symbols that verify the detection and fine-tune timing (±6 ms). Data symbols carry one nibble per band (16-tone FSK, Hann-windowed Goertzel detection).

FAST1.5–7.4 kHz4 × 1634 ms8 B64 B
ROBUST0.9–4.8 kHz2 × 1658 ms16 B32 B

Frame: chirp · training · header(magic|mode, len, flags, CRC-8)+RS(6) · payload+CRC-32+RS(n).

Session layer

10-byte header: type|ver, flags, sid, seq, ack, SACK bitmap, window. Types SYN, SYN-ACK, ACK, DATA, FIN, RST, KA. Flags TURN, FIRST, LAST, NACK, ROBUST.

  • Handshake SYN → SYN-ACK → ACK with random ISNs and a 16-bit session id (several sessions can share a room).
  • Half-duplex turns: a burst of ≤ window frames ends with TURN; the peer answers with cumulative ACK + 8-bit selective-ACK bitmap. Missing frames are NACKed and resent first.
  • Listen-before-talk: never transmit while a frame is being received.
  • Timers: RTO from airtime with 1.5× backoff, delayed ACK if TURN is lost, keepalive every 20 s, FIN/FIN handshake, RST abort.
  • Adaptation: ≥50% loss in a burst, 2 timeouts, or a peer ROBUST request → switch to ROBUST and window 2; after 4 clean bursts return to the preferred mode.

No encryption, no authentication: an eavesdropper can read and a nearby speaker can inject. This is by design for the OSS edition.
